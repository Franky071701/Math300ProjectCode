# Math300ProjectCode

### Dijkstra's Algorithm vs. Duan et al. (2025) SSSP
A Python implementation and performance comparison of Dijkstra's algorithm (1959) and the simplified Single-Source Shortest Path (SSSP) algorithm by Duan et al. (2025) on 2D weighted grids, random graphs, and real-world road networks (Richland, WA via OSMnx).

### Prerequisites & Installation
1. Create and activate a Python virtual environment:
   * **Windows (CMD):** `.venv\Scripts\activate`
   * **Windows (PowerShell):** `.\.venv\Scripts\Activate.ps1`
   * **macOS/Linux:** `source .venv/bin/activate`
   
2. Install the required packages:
   ```bash
   pip install numpy matplotlib seaborn osmnx networkx pillow
     ```
### How to run
There are two ways to run a file
1. More technical way
  ```
  Windows: path\to\env\Scripts\python.exe your_script.py.
  macOS/Linux: path/to/env/bin/python your_script.py
  ```
2. Simple
  ```
``python <filename>.py or python3 <filename>.py
  ```
