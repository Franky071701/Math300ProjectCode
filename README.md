# GroupProjectCode

### A* (A-star) vs Dijkstra's

A comparison between A* and Dijkstra's to see how each algorithm functions on certain grid types, to be more specific, how they function on a 2D grid (video game style) and on a real map (using Real Data). 

### Prerequisites 
In order to test this locally (on your own computer), there are 2 things that you would need in order for this to work:
1. A Python environment (venv) which can be done in the Terminal or Command Prompt by doing the following:
   For Windows
   ```
    Windows (Command Prompt): .venv\Scripts\activate
    Windows (PowerShell): .\.venv\Scripts\Activate.ps1
   ```
   For Mac
   ```
   ./venv/bin/activate
   ```
2. Have the right modules
   - Note: By making the environment it should already install everything if not, you might need to it manually
     ```
     pip install <the module name>
     ```
### How to run
There are to ways to run a file
1. More technical way
  ```
  Windows: path\to\env\Scripts\python.exe your_script.py.
  macOS/Linux: path/to/env/bin/python your_script.py
  ```
2. Simple
  ```
``python <filename>.py or python3 <filename>.py
  ```
